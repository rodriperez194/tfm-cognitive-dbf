01 · Project Overview

Adaptive beamforming under dynamic interference

Modern radar and sensing systems may operate in electromagnetic environments affected by multiple directional interference sources. Static beamforming strategies can become insufficient when those conditions evolve over time.

This project develops a modular simulation framework in which digital beamforming weights can be adapted dynamically while preserving the response towards the Signal of Interest (SOI).

01

Digital Array Model

Narrowband antenna-array modelling with complex steering vectors, configurable geometry and beamforming weights.

02

Classical Beamforming

Reference beamformers including conventional steering, deterministic interference nulling and MVDR-based approaches.

03

Multi-Jammer Scenarios

Dynamic scenarios containing a known SOI and multiple directional jammers with configurable power and motion.

04

Perception and Tracking

Direction-of-arrival information can be integrated with temporal tracking to provide estimated jammer directions to the beamforming controller.

05

Cognitive Control

Deep Reinforcement Learning agents learn policies that adapt the beamforming configuration according to the observed electromagnetic scenario.

06

Physical Metrics

Performance evaluation through SINR, SOI gain, jammer suppression and radiation-pattern analysis.

02 · Framework

Modular processing and decision pipeline

The framework separates the physical simulation, perception and beamforming-control components. This makes it possible to evaluate individual modules and compare cognitive policies against classical beamforming references under equivalent scenarios.

03 · Demonstration

Minimal executable example

The public repository intentionally contains a reduced and self-contained subset of the complete research framework. Its purpose is to illustrate the principal simulation workflow without reproducing every experiment, trained agent or internal development artifact used during the thesis.

What the notebook demonstrates

  • Array and scenario configuration
  • SOI and jammer direction definition
  • Beamforming-weight computation
  • Lookup-table based configuration when available
  • Radiation-pattern visualization
  • Physical performance metrics

05 · Running the Demo

From clone to execution

Python dependencies are provided through requirements.txt. A virtual environment is recommended.

1

Clone the repository

git clone https://github.com/rodriperez194/tfm-cognitive-dbf.git
cd tfm-cognitive-dbf
2

Create a virtual environment

python -m venv .venv
3

Install the dependencies

python -m pip install --upgrade pip
pip install -r requirements.txt
4

Run the demonstration

Open demo.ipynb with Jupyter or Visual Studio Code and execute the cells in order.
